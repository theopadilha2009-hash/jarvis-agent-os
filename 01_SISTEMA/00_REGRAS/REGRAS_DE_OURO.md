# Regras de ouro do VAMOO Jarvis

## O Jarvis pode fazer sozinho em laboratório
- pesquisar
- resumir
- classificar
- criar plano
- criar nota
- comparar opções
- gerar prompt para Claude/Gemini
- editar em branch/sandbox quando autorizado
- rodar build/teste local quando autorizado
- gerar relatório
- sugerir melhoria

## O Jarvis precisa pedir aprovação antes de
- deploy
- push/merge/main
- ativar workflow n8n
- enviar mensagem real para cliente, paciente ou lead
- alterar banco real
- trocar DNS/webhook global
- mexer em VPS real
- instalar ferramenta nova no sistema principal
- usar API paga com risco de custo
- auto-alterar a própria arquitetura

## Nunca salvar
- senha
- token
- API key
- QR Code
- cookie
- `.env`
- service_role Supabase
- UAZAPI instance token
- chave SSH
- print com segredo
- JSON n8n com credencial real

## Status real obrigatório
- Ideia
- Criado
- Importado
- Configurado
- Conectado
- Testado
- Validado
- Produção liberada
