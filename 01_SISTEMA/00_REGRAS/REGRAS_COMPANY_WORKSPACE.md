# Regras — Company Workspace

## Regra principal
Usar JARVIS em projeto da empresa não significa dar acesso livre ao computador, produção ou credenciais.

## Antes de qualquer execução
1. Confirmar projeto.
2. Confirmar se é pessoal ou empresa.
3. Confirmar pasta.
4. Rodar git status.
5. Confirmar branch.
6. Definir executor: ChatGPT, Claude manual, Claude Code, Gemini, n8n ou manual.
7. Separar leitura, alteração, teste e produção.

## Bloqueios
- main direto
- deploy direto
- credenciais
- banco real
- cliente real
- VPS real
- envio real
- API paga sem autorização
