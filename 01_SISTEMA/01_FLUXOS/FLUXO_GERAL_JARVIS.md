# Fluxo geral do Jarvis

## Fluxo ideal
Goal do usuário
→ Task criada
→ Contexto buscado
→ Risco classificado
→ Ferramenta escolhida
→ Plano seguro
→ Execução em laboratório/branch
→ Teste ou verificação
→ Auto-revisão
→ Memória atualizada
→ Relatório gerado
→ Aprovação humana se houver risco

## Papéis
- ChatGPT: cockpit, estratégia, resumo, decisão e prompt curto.
- n8n: orquestrador, fila, logs, automações e aprovações.
- Obsidian/Markdown: memória viva.
- Claude Code: executor premium de código/repo.
- Gemini CLI: backup/free-first para pesquisa e execução não sensível.
- Groq/OpenRouter: classificação e resumo barato.
- Playwright: teste de browser e evidência.
- Git: proteção, branch, diff e rollback.
- Ruflo: laboratório futuro para multiagente/autopilot.
