# Decisor de ferramentas

## Se for bug em código/repo
Use Claude Code em branch segura. Gemini CLI pode revisar ou ajudar em baixo custo.

## Se for workflow n8n
Use análise JSON sanitizada, mock/dry-run, active=false, logs e Error Trigger.

## Se for memória/documentação
Use ChatGPT/Claude para gerar Markdown e salvar em `03_MEMORIA` ou `04_PROJETOS`.

## Se for pesquisa de ferramenta
Usar web/research e salvar em `03_MEMORIA/03_FERRAMENTAS`.

## Se for site/portfólio
Usar branch local, build/test, preview e aprovação antes de publicar.

## Se for VPS
Primeiro read-only, backup/snapshot, plano, depois comando autorizado.

## Se for algo de cliente/paciente/lead
Humano aprova antes de envio real ou ativação.
