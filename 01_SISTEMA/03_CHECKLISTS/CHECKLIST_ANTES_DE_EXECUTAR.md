# Checklist antes de executar

- [ ] Sei qual é o projeto?
- [ ] Sei se é laboratório, staging ou produção?
- [ ] Tem risco de segredo?
- [ ] Tem risco de custo?
- [ ] Tem risco de cliente real?
- [ ] Existe branch/sandbox?
- [ ] O próximo passo é reversível?
- [ ] Está claro o status real?
- [ ] Precisa de aprovação humana?
