# JARVIS Opportunity

Nicho: academias pequenas que atendem pelo WhatsApp

## Decisão rápida

- Melhor ideia inicial: Mini landing page + WhatsApp rastreável para academias pequenas que atendem pelo WhatsApp
- Motivo: fácil de demonstrar, rápido de entregar e simples de vender
- Produto de entrada: demo + página simples + botão WhatsApp
- Preço piloto: R$ 297 a R$ 700
- Upsell: automação WhatsApp, resumo de leads e follow-up
- Mensalidade possível: R$ 150 a R$ 300/mês

## Mensagem para prospect

```text
Oi, tudo bem?

Vi que negócios como academias pequenas que atendem pelo WhatsApp normalmente dependem muito do WhatsApp, mas acabam perdendo interessados porque a apresentação, o link e a próxima ação ficam meio soltos.

Montei uma ideia simples: uma mini landing page com botão de WhatsApp rastreável e uma estrutura básica para captar melhor os contatos.

A ideia é começar com uma demo rápida, sem compromisso grande, só para validar se isso ajuda a gerar mais conversas boas.

Posso te mostrar uma primeira versão?
```

## Comando para gerar pacote completo

```bash
./jarvis-full "Academias Pequenas Que Atendem Pelo Whatsapp Teste" "Mini landing page + WhatsApp rastreável para academias pequenas que atendem pelo WhatsApp"
```
