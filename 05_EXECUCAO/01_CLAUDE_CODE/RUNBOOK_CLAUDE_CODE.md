# Runbook Claude Code

## Read-only primeiro
Usar antes de qualquer edição:
- confirmar pasta
- git status
- branch
- arquivos relevantes
- plano mínimo
- risco de segredo/produção

## Patch seguro
Depois de autorizado:
- alteração mínima
- sem main
- sem refatorar fora do escopo
- sem commit/push/deploy
- build/teste possível
- resumo final com arquivos e riscos
