# Plano manual (Theo executa)

## Pedido
preparar identidade pessoal do JARVIS com modos personal, work assist e future company

## Etapas seguras propostas
1. Rodar `./jarvis ask "<pedido>"` para ver classificação local + comando seguro.
2. Se ficar `unclear`, anotar com `./jarvis capture "..."` ou `./jarvis agenda-add "..."`.
3. Rodar `./jarvis cheatsheet` para lembrar atalhos.
4. Rodar `./jarvis doctor-agent` se algo parecer travado.
5. Quando Claude voltar: `./jarvis go "<pedido refinado>"`.
