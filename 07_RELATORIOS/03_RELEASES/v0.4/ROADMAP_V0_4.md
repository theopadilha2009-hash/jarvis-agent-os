# ROADMAP v0.4 — JARVIS Theo Padilha AI Worker

## Status real
Planejamento técnico. Nada conectado. Nada em produção.

## Objetivo da v0.4
Preparar o JARVIS para usar executores externos de forma controlada, começando por modo manual e depois evoluindo para CLI/API/sandbox.

## Blocos da v0.4
1. Executor Contracts
2. Manual Executor Pack
3. Prompt Generator
4. Output Intake
5. Review Result
6. Memory Capture
7. Quality Gate antes/depois
8. Preparação para Claude/Gemini/Ollama/Groq/n8n

## Regra central
JARVIS nunca deve entregar controle total para uma IA externa sem perfil, risco, plano, log, contexto mínimo e aprovação humana quando necessário.

## Ordem recomendada
1. ChatGPT cockpit manual
2. Claude/Gemini manual
3. Ollama local simples
4. Gemini CLI em sandbox
5. Claude Code em sandbox
6. Groq/API barata para classificação
7. n8n como orquestrador
8. voz/app/dashboard depois
