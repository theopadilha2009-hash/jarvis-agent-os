# jarvis_core.py backups (archive)

Historical snapshots of `11_SCRIPTS/jarvis_core.py` taken during v0.5/v0.6
development (around 2026-05-20).

- These are **not live scripts**.
- They are **not imported, executed, or referenced** by the JARVIS runtime
  or by the `./jarvis` CLI.
- They are kept **only for traceability** — to inspect how `jarvis_core.py`
  evolved across specific feature branches/checkpoints.
- Do **not** edit. Do **not** restore by overwriting `jarvis_core.py`
  directly; use git instead.

Filename pattern: `jarvis_core.py.bak-<tag>-YYYYMMDD-HHMMSS`.

Moved here from `11_SCRIPTS/` during v0.7 housekeeping so live executable
scripts no longer sit beside stale backups.
