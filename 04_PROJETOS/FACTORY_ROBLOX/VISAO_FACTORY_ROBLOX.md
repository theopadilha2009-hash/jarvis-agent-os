# Factory Roblox — visão inicial

## Ideia
Fábrica de jogos/workflows Roblox com múltiplas camadas de agente, revisão, validação e potencial comercial.

## Camadas possíveis
- Idea Scout
- Market Research
- Game Designer
- Economy/Monetization Agent
- Asset Planner
- Code Planner
- Static Validator
- Fun Judge
- Stage Governor
- Contract Judge
- Launch Agent
- Human Approval Gate

## Regra
Publicação real/manual somente após validação humana. Primeiro laboratório.
