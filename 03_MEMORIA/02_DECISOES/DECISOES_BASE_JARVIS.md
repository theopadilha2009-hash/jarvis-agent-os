# Decisões base do Jarvis

1. O sistema começa como laboratório local.
2. n8n será o orquestrador, não o cérebro único.
3. Obsidian/Markdown será a memória.
4. Claude Code será o executor principal para código.
5. Gemini CLI/Groq entram como apoio barato/free-first.
6. Ruflo só entra depois em sandbox.
7. Produção, cliente real, banco real, deploy e VPS real exigem aprovação.
8. Auto-melhoria só com proposta, sandbox, teste e aprovação.
